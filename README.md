# Ameer Tayeh Portfolio (React + Vite)

Modern portfolio website built with React, Vite, Tailwind CSS, and Lucide icons.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## GitHub Pages deployment

A GitHub Actions workflow is included at `.github/workflows/deploy.yml`.

- Enable **GitHub Pages** in repository settings.
- Set source to **GitHub Actions**.
- Push to `main` (or run manually) to deploy.
